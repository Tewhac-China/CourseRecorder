How it works

核心能力详解

四个环节环环相扣，把"一段录像"变成"一份可检索的课程资料"。

① 投影区域标定与透视矫正

摄像头往往无法正对幕布，直接拍到的画面是梯形。CourseRecorder 会先找到幕布的四个角， 再做透视变换，输出一张"正面视角"的清晰图像。

  • 自动检测：基于边缘与亮度对比自动定位四角，开箱即用
  • 手动标定：点击幕布四角，适合自动检测不准的场景（最可靠）
  • 逐帧跟踪：幕布轻微移动或被遮挡后自动重新锁定
  • 四角稳定：内置平滑算法，避免角点抖动导致画面跳动
处理流程
1摄像头采集原始画面
2检测/标定四角
3透视变换 (WarpPerspective)
4输出拉正的正面图

② 幻灯片自动提取

课程中老师会不断翻页。程序持续比对当前画面与上一张已保存的幻灯片， 只有当内容真正发生变化时才截图保存，避免录下一堆重复图片。

  • 感知哈希：对画面缩放去色后计算指纹，抗光照与微小抖动
  • 自动去重：相似画面不会重复保存
  • 时间线编号：文件名带时间戳，与转写文稿可对齐回溯
  • 手动补拍：漏拍时可按键手动提取当前画面
判断逻辑
1矫正后画面
2计算感知哈希指纹
3与上一张对比差异
4差异超阈值 → 保存新幻灯片

③ 实时语音转写

音频被切成短窗口送入本地 ASR 模型，转写结果流式追加到时间线， 录制结束即得到完整文稿。所有推理都在本机完成，音频不会上传到任何服务器。

  • 双引擎可选：SenseVoice（中文更快更准）/ Whisper（多语言更强）
  • VAD 静音检测：过滤无人说话的片段，减少无效输出
  • 实时性：数秒窗口滚动转写，录制中即可看到文字
  • 离线可用：模型下载后完全无需联网
音频处理链
1麦克风 / 系统声音采集
2VAD 静音过滤
3本地 ASR 模型推理
4追加到时间线 + 实时显示

④ 笔记生成与输出

录制结束后，幻灯片与转写文字按时间对齐，自动整合成一份结构化 Markdown 笔记； 若开启翻译，会同时生成中文译本。

  • notes.md：幻灯片 + 对应转写文字，带时间戳
  • notes_translated.md：翻译后的中文笔记
  • slides/：按序编号的幻灯片图片
  • transcript.jsonl / slides.jsonl：结构化时间线，便于二次开发
录制产出
📄notes.md — 原文笔记
🌏notes_translated.md — 译文笔记
🖼️slides/ — 幻灯片图片序列
🔗*.jsonl — 时间线数据

📊 各模型显存占用参考

实际占用会随音频窗口长度与并发任务浮动：

  • SenseVoiceSmall：约 1 GB 显存（模型本身仅 254 MB）
  • Whisper tiny / base：约 1 GB
  • Whisper small：约 2 GB
  • Whisper medium：约 5 GB
  • Whisper large-v3：约 10 GB
  • Qwen3-0.6B INT4：约 0.7 GB
  • Qwen3-1.7B INT4：约 1.5 GB

💡 配置建议

  • 优先保证内存：建议 16GB 起步，模型加载与音频缓冲都吃内存
  • 先跑起来再升级：默认 SenseVoiceSmall 对硬件最友好，中文课首选
  • 翻译可关：只需要中文转写时关闭翻译，能省下 1.5GB 显存
  • 笔记本务必插电：GPU 满载时电池供电会降频，且耗电极快
  • 显存不足会自动降级：程序检测到显存不够时会自动回退到 CPU 或更小模型
Known limitations

已知不足

我们选择如实列出当前的短板，避免给你不切实际的预期。

🔋 本地运行耗电快

转写与翻译模型会让 CPU/GPU 持续高负载，笔记本电池续航明显缩短， 长时间录制时机身发热也比较明显。

缓解：录制时尽量连接电源；关闭翻译功能； 改用 SenseVoiceSmall 或 Whisper tiny/base 等轻量模型可显著降低功耗。

⏳ USB 摄像头启动慢

USB 摄像头需要经历 DSHOW 驱动初始化、分辨率与像素格式（MJPG）协商等步骤， 从点击"打开摄像头"到出现画面通常需要数秒，切换或重连设备时等待更明显。

缓解：程序已做格式协商与连接状态提示（蓝色待连接 / 黄色连接中 / 绿色已连接）； 避免频繁切换视频源；优先使用原生支持 MJPG 的摄像头。

🎛️ 难兼容手动变焦 / EV / ISO

多数廉价 USB 摄像头并未通过 UVC 暴露手动控制接口，OpenCV 无法调节对焦、EV、ISO、增益等参数— 这不是程序限制，而是摄像头硬件/驱动本身不支持。

缓解：程序会自动探测可用属性与范围，支持的项目（如亮度、对比度、 饱和度、色调、曝光）正常调节，不支持的显示为灰色并标注原因。

其他需要注意的点

  • 平台覆盖：主要在 Windows 10/11 上测试，Linux / macOS 尚未完整验证
  • 首次模型下载：首次运行会下载数百 MB 至数 GB 的模型文件，请确保网络畅通
  • 环境依赖：强光直射幕布、幕布与墙面对比度过低时，投影区域检测率会下降，建议手动标定
  • 录制合规：录制他人课程前请务必获得授课者同意
Quick start

快速开始

三步跑起来，无需复杂的环境配置。

1

安装依赖

建议使用 Anaconda 创建独立环境（Python 3.9+）。

conda create -n cr python=3.11
conda activate cr
pip install -r requirements.txt
2

启动程序

运行主程序，或直接双击 Windows 启动脚本。

python main.py
# 或双击 run.bat
3

开始录制

选择视频源 → 打开摄像头 → （可选）标定投影区域 → 开始录制。

打开摄像头 → 标定投影区域
→ ● 开始录制 → ■ 停止录制
